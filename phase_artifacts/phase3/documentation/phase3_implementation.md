# Phase 3 Implementation Report

## Goal
Integrate an LLM into the support workflow and compare multiple prompt strategies on the same fixed test set.

## What Was Implemented
- LangChain OpenAI client wrapper for chat inference
- Three prompt variants:
  - A: Naive assistant
  - B: Role + policy constraints
  - C: Structured safety + escalation output guidance
- Fixed prompt evaluation test set
- Prompt comparison runner producing:
  - machine-readable JSON results
  - human-readable markdown comparison table

## New Phase 3 Files
- `src/phase3/prompt_variants.py`
- `src/phase3/llm_client.py`
- `src/phase3/prompt_evaluator.py`
- `data/phase3/prompt_eval_test_set.json`
- `scripts/run_phase3_prompt_eval.py`
- `reports/phase3_prompt_comparison.md` (generated by script)
- `outputs/phase3/prompt_comparison_results.json` (generated by script)

## Prompt Strategy Decision
Default prompt strategy: Variant C.

Justification:
- Strongest explicit safety behavior and escalation guidance.
- Better auditability due to structured output direction.
- Lower risk of silent policy drift compared with A/B.

## New Failure Modes Introduced by LLM (Expected)
- Verbose answers that reduce operational speed.
- Overconfident wording when evidence is weak.
- Occasional instruction overfitting to formatting constraints.

## Why This Advances Beyond Phase 2
- Phase 2 baseline was deterministic and brittle.
- Phase 3 introduces semantic generalization and richer language handling.
- Prompt-level controls improve safety behavior and decision consistency.
